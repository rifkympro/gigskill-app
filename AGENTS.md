# Aturan Pengembangan Proyek GigSkill

## Aturan Git & GitHub
- **DILARANG** melakukan `git push` ke repositori GitHub secara otomatis tanpa instruksi atau konfirmasi eksplisit dari pengguna.
- Setiap perubahan kode harus diuji dan dikompilasi terlebih dahulu di workspace lokal AI Studio.
- Hanya lakukan `git push` ketika pengguna secara spesifik meminta: "Tolong push ke GitHub" atau konfirmasi serupa.
